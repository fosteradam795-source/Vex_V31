# Vex_V31

Vex is a beginner-friendly, dot-syntax programming language (`.vx`) paired with a custom terminal environment (`Vex.exe`). Designed to bridge readable syntax with multi-engine execution, Vex v31 combines Python, C++, and Rust backends into a single lightweight workflow.

## What's Included in `vex_V31.zip`
* **Core Runtime & Terminal:** `vex_app.py`, `vex_lang.py`, `vex_os.py`, and `vex_term.py`
* **Security & Auto-Fix Utilities:** Built-in syntax auto-correction (`vex_autofix.py`) and security checks (`vex_sec.py`)
* **Multi-Engine Support:** Native C++ (`vex_cpp.cpp`) and Rust (`Cargo.toml` / `main.rs`) execution engines
* **Build & Demo Files:** One-click build script (`build_all.bat`), custom app icon (`vex.ico`), and a sample script (`demo_v31.vx`)

## Quick Start
1. Download and extract `vex_V31.zip` from the **Releases** section on the right.
2. Run `build_all.bat` to compile the engines and package the application, or launch `vex_app.py` directly.
3. Test out the language syntax using `examples/demo_v31.vx`.
